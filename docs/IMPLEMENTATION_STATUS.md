# Implementation Status

This is the current handoff status for the project.

## Implemented

- Six-game Wii U catalog with stub resolution and accepted title IDs.
- User-supplied ROM workflow:
  - recursive `roms/` scan,
  - persisted external paths,
  - native picker fallback,
  - extracted title and title-ID validation paths.
- User-supplied key workflow with `keys/keys.txt` and native setup errors.
- Bundled external Cemu build path from `extern/cemu`, including output copy to `cemu/Cemu.exe`.
- Cemu resolution fallback for persisted external, portable local, legacy, and picked Cemu executables.
- Hidden Ultralight boot flow:
  - Cemu launches automatically,
  - overlay stays hidden until toggled,
  - `F1` always works,
  - configurable user overlay toggles are persisted.
- Character selector overlay:
  - game-clamped selector,
  - toy categories,
  - wheel/list assets with render/icon fallback,
  - visible portal slots,
  - place/clear actions,
  - diagnostics/setup panel.
- Cemu-generated character catalog:
  - 481 Cemu-creatable entries,
  - variants, traps, items, vehicles, trophies, and SWAP halves,
  - generated C++ include and JSON manifest.
- Asset tooling:
  - local render assignment,
  - Skylanders Character List render import,
  - Skylanders Wiki icon import,
  - element icon import,
  - asset-gap report generation.
- Portal placement pipeline:
  - launcher-to-Cemu named pipe,
  - `place_or_create`,
  - response parsing,
  - native/UI error reporting,
  - UI updates only after confirmed success.
- Controller mapping:
  - Player 1 and optional Player 2 profiles,
  - device scanning through bundled Cemu input IPC,
  - session-based capture/poll/cancel,
  - keyboard and controller default profiles,
  - overlay-toggle binding management.
- Graphic-pack update and diagnostics:
  - version-6 ZIP discovery/download,
  - cache under `runtime/downloads/`,
  - extraction into `cemuRoot/graphicPacks`,
  - 7-day auto-check,
  - manual update bridge,
  - selected/missing pack diagnostics,
  - non-fatal launch warnings.
- Per-game Cemu preparation:
  - Vulkan,
  - async shader compile,
  - accurate Vulkan barriers,
  - GX2Drawdone sync,
  - Skylander portal emulation,
  - per-game MLC paths,
  - controller profile references,
  - resolution preset selection,
  - optional fullscreen setting,
  - conservative audio defaults.

## Still Needed For A Complete V1

- Package/release script that produces a clean distributable folder.
- Fresh-machine setup test from clone through first game launch.
- More reliable non-XInput overlay toggle support for devices such as SDL/DualSense when the overlay is hidden.
- Better controller capture feedback for devices whose input is consumed by Cemu/game focus.
- Figure persistence investigation:
  - confirm when Cemu flushes `.sky` save state,
  - document expected save timing,
  - add tests around create/load/reload behavior where possible.
- Full setup/diagnostics UI pass for first-run failure cases.
- Automated UI regression checks against the real Ultralight runtime.
- CI or scripted verification for both normal and bundled builds.
- Installer or updater story for users who do not build from source.

## Deferred Larger Work

- True in-process embedded Cemu via `SKYLANDERS_EMBED_CEMU`.
- Embedded render-host integration instead of an external overlay window.
- Input interception that prevents games from seeing mapping/toggle inputs.
- Native ZIP extraction library instead of relying on Windows/PowerShell extraction behavior.
- Upstream-quality Cemu patch separation for easier rebasing.
- Online asset updater with review/approval workflow built into the app.

## Known Fragile Areas

- `extern/cemu` is patched locally. Rebase carefully and test portal/input IPC after every Cemu update.
- Graphic-pack matching is heuristic. It reports diagnostics, but pack folder/rules naming can change upstream.
- Some asset matches are manually assigned. Regenerate the gap report after catalog or asset changes.
- The frontend is optimized for Ultralight, not only a desktop browser. Avoid CSS features that render differently in Ultralight without testing in the actual overlay.
- Runtime config files are intentionally lightweight JSON/XML generated by local helpers. Schema changes should include migration or tolerance for older files.

## Recommended Next Milestones

1. Stabilize controller mapping and device capture across Keyboard, XInput, SDL, and DualSense devices.
2. Verify `.sky` figure persistence end to end with bundled Cemu and document exact behavior.
3. Add packaging automation and a clean "release smoke test" checklist.
4. Add automated visual/UI checks for the overlay.
5. Prepare the Cemu patch set for easier long-term maintenance.
